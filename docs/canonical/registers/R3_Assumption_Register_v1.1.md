An assumption is something the project currently relies on without proof. Each one has a validation method and a trigger for revisiting it. Assumptions are **not** decisions (R2) or risks (R4), although a failed assumption usually becomes a risk.

**Types:** DOC = about the evidence base · PRD = product/market · TEC = technical · LEG = legal/governance · COM = commercial · OPS = working method.
